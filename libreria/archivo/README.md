# Archivo de scripts de dibujo antiguos

Scripts con los que se dibujaron los SVG de vídeos ya publicados (una carpeta por vídeo), guardados tal cual como referencia.
No son piezas de la librería: si algo de aquí sirve para otro vídeo, conviértelo en función de `libreria/svg/` y documéntalo en
`libreria/README.md`. Útiles sobre todo para animales (pulpo, hormiga, escarabajo, gecko, pez), volcán, géiser, hipo y cerveza.
